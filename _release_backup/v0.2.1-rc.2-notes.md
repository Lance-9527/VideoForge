# VideoForge v0.2.1-rc.2

**用一句话把创意变成成片的私人 AI 短片 Agent 桌面软件。**

## 这是什么

一个 Windows 桌面软件：你在对话框里描述创意，它把「AI 写剧本 → 抽角色场景 →
出定妆照与场景图 → 拆分镜 → 白膜预演 → 480P 小样 → 1080P 成片 → 后期合成」
整条流水线做成对话式 agent —— 每一步的**确认卡**递给你，点「确认，开始做」即可推进，
不用反复打字，也不用在多个页面之间跳。

## 架构

- **DSH 底座**（`deepseek-harness-master`）做 agent 运行时 / 工具协议 / 后台任务 / 审批 / 界面外壳
- **`packages/video/vf-video`** 是我们的 bundle（薄壳，10 个粗粒度工具 + 9 步 DAG + 面板）
- **Python sidecar**（`apps/desktop/resources/videoforge-sidecar/_internal/backend/`）是业务本体
  —— 九阶段流水线、79 个工具、适配器、白膜引擎、合成、预算、SQLite
- **唯一数据源 = sidecar 的 SQLite**；DSH 会话只存引用（project_id / stage / job_id）

## 几条纪律（写在 bundle 里，别破坏）

1. 执行入口只有一个：`core.agent_tools_stages.run_stage`
2. 进度不另造一套：一律读 `core.stages` 的 EVIDENCE
3. 金额不另写一套：单价走 `core.shot_segments` 价格表，余额/闸门走 `core.budget`
4. 不动业务数据：sidecar 只写 `tasks` 表

## 亮点

- **角色一致性**：用户给定的角色基准优先于项目内多数派；基准角色每镜必带参考图
- **转镜衔接**：跨镜接龙（上一镜尾帧当下一镜首帧）+ 场景锚点表（道具不换边）
- **白膜 → 关键帧 → 成片**：白膜预演的构图真的落到成片，不只是给用户看一眼
- **花钱刹车**：预算不够直接拒绝生成，不会"点了没反应"

## 数据与隐私

项目数据只在本机（`%LOCALAPPDATA%\VideoForge\data`），不上传。
API Key 由用户在设置里填，存本地库 —— 仓库里不含任何凭据。
