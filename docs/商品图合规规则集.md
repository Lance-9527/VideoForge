# 商品图 / 商品视频 · 合规规则集

> 2026-10-27 · 配套代码 `core/commerce_rules.py` + `core/data/commerce_rules.json`

## 为什么做这个

「生成得好看」已经免费了 —— 稿定 **¥0.08/张**、阿里 Pic Copilot **免费**。
但**「能不能过审」没人管**，而这才是真成本：

| 事项 | 成本 |
|---|---|
| 生成一张图 | ¥0.08–0.5 |
| 一张图被判违规导致降权/限流/下架 | **几百到几千**（损失的是整批货的曝光） |
| 国内合规红线（AI 内容必须标识） | **违法**（《标识办法》第十三条） |

所以 VideoForge 在电商方向的价值锚点不是"生成得更快更漂亮"，而是：
> **「生成即过审」** —— 把平台规范和 AI 标识法规变成**可批量执行、可验证**的规则。

## 一、法律硬要求（法规级，可信度最高）

**《人工智能生成合成内容标识办法》**（国信办通字〔2025〕2 号，2025-03-07 制定，**2025-09-01 施行**）
来源：https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm

| 条款 | 要求（落到本工具的规则） |
|---|---|
| 第三条 | AI 生成合成内容 = 文本/图片/音频/视频/虚拟场景；标识分**显式**（用户可感知）+ **隐式**（文件元数据） |
| 第四条(三) | **图片**：在适当位置添加显著的提示标识 |
| 第四条(四) | **视频**：在**起始画面**和播放周边适当位置添加显著提示标识 |
| 第四条末款 | 提供下载/复制/导出功能时，**文件中必须含有**满足要求的显式标识 |
| 第五条 | 必须在**文件元数据**中添加隐式标识，含生成合成内容属性信息、服务提供者名称或编码、内容编号等；鼓励数字水印 |
| 第六条 | 传播平台要核验元数据中的隐式标识；用户声明为生成合成内容的，要加提示标识 |
| 第九条 | 提供**无显式标识**的内容，须先在用户协议明确标识义务，并依法留存日志**不少于六个月** |
| 第十条 | 用户发布生成合成内容**应当主动声明**并使用标识功能；**任何组织和个人不得恶意删除、篡改、伪造、隐匿标识** |
| 第十四条 | 自 **2025-09-01** 起施行 |

> ⚠️ **第十条的直接后果**：任何"去 AI 水印/去标识"的功能都是违规的。本工具提供的是
> `apply_ai_label_corner()`（**加**标识）和 `apply_ai_metadata()`（**写**元数据），不是去除。

## 二、规则集怎么用

```python
from core.commerce_rules import check_file, check_batch, apply_ai_label_corner, apply_ai_metadata

# 1) 出图后：加显式标识（像素层）+ 写隐式标识（元数据层）
p1 = apply_ai_label_corner("out/main.jpg", "out/main_labeled.jpg")
p2 = apply_ai_metadata(p1, "out/main_final.jpg",
                       tool="VideoForge", content_id="VF-SKU-0001")

# 2) 校验（按目标平台取规则）
r = check_file(p2, platform="pdd")
r["ok"]        # bool：没有 error 级问题（warn/manual 不阻断）
r["errors"]    # 阻断项：title / detail / fix / why / source_url
r["warnings"]  # 警告项
r["manual"]    # 机器判不了、要人确认的（水印、文字占比、商品占比…）

# 3) 批量（200 张 SKU 图的场景）
b = check_batch(paths, platform="pdd")
b["passed"], b["failed"], b["summary"]   # summary 按规则聚合：哪条最常不过
```

## 三、规则分级（**别当法律依据看**）

| 来源类型 | 可信度 | 含义 |
|---|---|---|
| `regulation` | **high** | 法规原文，直接是法律要求 |
| `official` | high | 平台官方文档 |
| `community` | medium | 行业共识值 —— **各平台/类目可能不同，请按自己类目的官方规则核对** |

规则表里 `confidence=medium` 的是通用默认闸门（如主图 ≥800px、1:1、白底），
**不是**"平台就是这么规定的"。真上线前请把自己类目的官方规则补进
`core/data/commerce_rules.json`（或做成用户可导入的规则包）。

## 四、当前 12 条规则

**法规级（4 条，阻断）**
1. `cn.ai_label.explicit.image` — 图片须有显式标识（**人工确认**，机器判不了"显著"）
2. `cn.ai_label.explicit.video` — 视频起始画面须有显著提示标识（人工确认）
3. `cn.ai_label.implicit.metadata` — 文件元数据须含隐式标识（**自动**，已验证）
4. `cn.ai_label.declare_on_publish` — 发布时须主动声明 + 用平台标识功能（流程项）

**平台通用（8 条，可信度 medium）**
5. `main.square` — 主图 1:1（自动）
6. `main.min_size` — 主图 ≥800px（自动）
7. `main.white_bg` — 白底图纯白背景（自动，pdd/douyin/amazon）
8. `main.no_watermark` — 无其它平台水印/文字/边框（**人工**）
9. `main.text_ratio` — 主图文字占比（**人工**）
10. `main.format` — 格式与体积（自动）
11. `main.white_ratio_amazon` — Amazon 商品占画面约 85%（**人工**）
12. `main.resolution_tier` — 多倍率图缺失（警告 + 人工）

## 五、能力边界（重要，别误以为它万能）

**能自动查**（有明确机器判据）：尺寸 / 比例 / 格式 / 体积 / 纯白背景 / 元数据是否含 AI 标识

**只能标人工**（机器不可靠）：是不是"别的平台"的水印 / 文字占比 / 商品占比 / 类目专属要求
→ 人工项**不阻断**，但会出现在报告里让你确认。

**角标检测**：故意做成**保守**（宁可报"需人工"也不自动判过）。
最初版本用"右下角与底色不同的像素比例"，结果**纯色背景图也判通过**（背景本身就和角点像素不同）——
这种误判很危险，会让人以为合规了。已修正为一律人工确认。
