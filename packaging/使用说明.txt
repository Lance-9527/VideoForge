VideoForge · 私人 AI 短片 Agent  v1.1.0
================================================

【这是什么】
  一个本地运行的 AI 短视频生产工作台：从想法 → 专业剧本 → 角色/场景/分镜 → 视频生成 → 后期成片。
  界面在本机运行（数据全部保存在你自己的电脑上，不上传云端）。

【环境要求】
  · Windows 10 1809（build 17763）或更高版本 / Windows 11
  · 无需 Python、无需 Node.js、无需 FFmpeg（均已内置）
  · 桌面窗口需要 WebView2 运行库（Win11 与多数 Win10 已预装；缺失时程序会自动改用浏览器模式，功能一致）
  · 首次使用需要配置至少一个 AI 模型的 API Key（见下方"首次使用"）

================================================
一、安装版（推荐）
================================================
  1. 把整个文件夹拷贝到目标电脑任意位置（U 盘、桌面均可）
  2. 双击【安装.bat】
  3. 按提示确认安装位置（默认装到当前用户目录，不需要管理员权限）
  4. 安装完成后会自动创建桌面与开始菜单快捷方式，并询问是否立即启动
  5. 以后从桌面快捷方式启动即可

  卸载：设置 → 应用 → 已安装的应用 → 找到「VideoForge · 私人 AI 短片 Agent」→ 卸载
        （或运行安装目录下的 卸载.bat）

================================================
二、便携版（免安装）
================================================
  1. 把【portable】文件夹解压到任意位置（建议路径不含特殊字符）
  2. 双击其中的 VideoForge.exe 直接运行
  3. 数据仍保存在 %LOCALAPPDATA%\VideoForge\data（换新版本只需替换程序文件）

================================================
三、首次使用（关键）
================================================
  1. 启动后点右上角【设置 AI】（齿轮/模型按钮）
  2. 【AI 对话模型】选择 Provider（DeepSeek / 通义千问 / 智谱 GLM / Kimi / MiniMax / 豆包 / 腾讯混元 / Ollama 本地）
     并填入对应的 API Key，点【测试 LLM】确认连通，再点【保存】
  3. 【视频模型 API Keys】至少配置一个（可灵 / 通义万相 / 即梦 / 海螺 / Runway / Sora 等）
  4. 回到 AI 对话，直接描述你的短片想法（或到「剧本」页点【💡 想法生成大纲】）
  5. 流程：剧本 → 角色/场景 → 分镜（可"自动从剧本生成"）→ 生成 → 后期（拼接/字幕/BGM/多比例导出）

  提示：
  · 对话中输入文字按 Enter 发送，Shift+Enter 换行
  · 左侧「会话」「项目」列表点击可随时切换
  · 剧本页的【想法生成大纲】会用 AI 生成专业编剧格式剧本（标题/梗概/逐场次动作与对白）

四、常见问题
================================================
  Q1. 双击没反应 / 一闪而过？
      → 查看日志：%USERPROFILE%\.videoforge\videoforge.log
      → 运行【环境诊断.bat】查看缺什么

  Q2. 提示缺少 WebView2？
      → 程序会自动改用浏览器模式打开（功能完全一致）
      → 想要桌面窗口体验，安装（免费，微软官方）：
        https://developer.microsoft.com/microsoft-edge/webview2/

  Q3. 提示"系统版本偏低"？
      → 本程序需要 Windows 10 1809 或更高。老系统（Win7/Win8）不支持。

  Q4. 杀毒软件报警 / 程序被删除？
      → 打包程序（PyInstaller）常被误报。请把安装目录加入杀软白名单。

  Q5. 生成剧本报错"额度不足 / 429"？
      → API Key 余额或套餐额度用尽，到 Provider 控制台充值或换一个 Key。

  Q6. 界面打不开但进程在运行？
      → 手动打开浏览器访问日志中显示的地址（形如 http://127.0.0.1:端口/）

  Q7. 想换电脑保留项目数据？
      → 复制 %LOCALAPPDATA%\VideoForge\data 整个目录到新电脑同一位置即可。

================================================
五、目录说明
================================================
  程序安装目录   %LOCALAPPDATA%\Programs\VideoForge
  用户数据       %LOCALAPPDATA%\VideoForge\data      （项目/剧本/会话/生成结果）
  日志           %USERPROFILE%\.videoforge\          （videoforge.log 等）
  环境诊断工具   程序目录下的 环境诊断.bat
